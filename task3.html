How the navbar works

Task 3. Make the browser window smaller and the menu will turn into a button.

navbar-brand

This class is for the logo. It stays on the left side.

ms-auto

This class pushes the links to the right side of the bar.

navbar-expand-lg

On small screens the links hide and the button appears.
